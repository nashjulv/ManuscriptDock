# Synthetic Fixtures

Fixtures in this directory must be synthetic, openly licensed, or intentionally created for testing.

Never add real unpublished manuscripts, peer-review reports, author identities, tokens, or institution-confidential rule material.

Future fixtures should cover:

- minimal valid manuscripts;
- malformed DOCX, PDF, and LaTeX inputs;
- anonymous and non-anonymous variants;
- rule inheritance and conflict cases;
- submission-package manifests;
- interrupted and resumed background tasks.
