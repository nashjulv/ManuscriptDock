# 投稿资料与目标投稿包

- 状态：V0.24 已实现
- 日期：2026-09-03
- 范围：单篇论文的本地投稿准备与作者控制导出

## 产品合同

每篇论文工作区拥有独立的投稿资料目录。Rust 负责选择文件、扩展名与大小校验、SHA-256、
去重、只读复制和审计；WebView 只接收安全元数据，不接收原始路径。

支持的资料类别包括源文件工程、匿名主稿、原始图件、可编辑表格、参考文献、补充材料、投稿信、
标题页、声明和其他附件。每个新材料绑定稿件版本、目标选择、官方要求快照和具体清单项；旧版本、
旧目标或旧要求快照中的附件保留在本地历史中，但不会自动混入当前投稿包。

导入时除大小、扩展名和 SHA-256 外，还会检查常见文件签名、PDF 可解析性与加密状态、DOCX/XLSX
容器结构，以及 DOCX 批注和修订跟踪提示。图件会提示作者继续按官方原文核验 DPI、尺寸和色彩空间。
验证不代替出版社投稿系统的最终接收检查。

## 投稿目标

期刊推荐仍是不可覆盖的本地运行记录。只有作者点击“设为投稿目标”，某个候选才成为这篇论文
当前的 `SubmissionTargetSelection`。选择记录保存推荐运行、期刊、出版社、等级、主页、
稿件版本和记录哈希；稿件版本更新后保留该选择，但在导出时提示重新核对。

V0.20 使用“一条主线 + 有序备选支线”。主线是唯一可登记投稿的目标；备选可提前形成独立的
官方要求快照和资料计划。提升备选时必须记录上一主线为尚未投稿、已拒稿或已完成撤稿，切换
形成不可变历史，避免产品暗示或协助一稿多投。

## 官方要求快照

每个目标选择拥有独立 `JournalRequirementSnapshot`。作者逐次授权后，Rust 仅访问期刊主页及
同站作者指南链接；请求限制为 HTTPS、公开网络地址、最多四页和每页 2 MB。页面正文只用于
确定性提取，工作区保存来源 URL、SHA-256、时间、短证据摘录和要求条目，不保存整页内容。

网页不可读时，作者可粘贴官方原文并确认来源。无明确证据条目时保持“待人工核验”，不会把
出版社通用基线冒充为该期刊的具体要求。快照默认 90 天后提示更新。

## 导出结构

导出前先显示逐文件组包预览，包括文件用途、目标上传槽位、包内相对路径、必需/可选状态、是否纳入、
校验提示和 SHA-256 摘要。作者可以排除当前材料；排除必需材料后预检立即转为阻断，Rust 后端也会
拒绝绕过界面直接导出。一个文件只能完成它明确绑定的清单项，多个图件或表格不会再由单个附件代替。

双盲不是默认模式。只有当前目标的官方证据明确要求匿名投稿时，组包才会启用匿名安全模式：
`submission/` 使用独立匿名稿作为主稿，实名源稿不会写入该目录，标题页按独立上传项保留。仅发现
“匿名评审”字样但未识别到强制义务时，系统要求人工核验，不自动切换为双盲包。

目标投稿包严格分为：

```text
package/
├── submission/   # 作者实际向出版社上传的主稿及附件
├── records/      # 目标选择、官方要求快照和检查报告，仅供本地留档
└── README.txt    # 上传边界与警告
```

`records/package-manifest.json` 记录每个计划文件的用途、绑定清单项、纳入状态、相对路径和内容指纹，
便于导出后复核；`submission/` 中只写入预览中已纳入的当前材料。

旧的检查报告、HTML 预览和存证合集被重新定义为“内部审核档案”，不能再称为出版社投稿包。

## 投稿登记

ManuscriptDock 不登录或模拟期刊系统。作者在真实期刊网站完成操作后，勾选确认并登记目标、
稿件号或回执。若当前版本尚无本地存证，Rust 在同一动作中自动创建作者确认存证，再保存投稿
记录。导出不等于投稿成功，登记也不代表录用或出版。

## 后续预览能力

V0.24 的“预览”是可靠的文件装配预览，不是文档实页渲染。下一阶段计划在本机加入 PDF、Word 和
LaTeX 的真实页面预览，以及修订版本的页面并排和可视化差异；在本地渲染链完成前，产品不会把提取
文本或结构统计称为版面预览。
