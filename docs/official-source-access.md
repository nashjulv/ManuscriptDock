# 官方来源读取与 HTTP 兼容（V0.45）

## 来源记录与网络访问

期刊画像、模型发现线索、学校政策和作者粘贴原文的来源网址接受合法 HTTP／HTTPS。
保存网址不会触发联网；不接受嵌入用户名或密码的 URL。模型 API 的远端 HTTPS 规则保持不变。

期刊要求由 Rust 受控读取。用户每次勾选一次授权后，首先使用有效来源网址中明确写出的协议。
连接、证书、超时、DNS 或 HTTP 状态失败均保留原因；不会将失败表述为“网站仅支持 HTTP”。
本次公开页面授权同时覆盖 HTTP 和 HTTPS，不再显示 HTTP 专属勾选或二次确认。
HTTP 地址先请求 HTTP，HTTPS 地址先请求 HTTPS；连接、证书、超时、DNS 或 HTTP 状态
异常时自动尝试另一协议，同一地址最多尝试两种协议。成功时不作另一协议的探测。
私网拦截、未授权域名、加密 DNS 恢复失败、解析及大小上限错误不通过切换协议绕过。
站点主动重定向仍受同样校验；已核验的目录修正单独记录。
HTTPS 证书验证始终启用。跨域链接或重定向必须逐个确认其官方身份及精确主机名，
包括同一出版社的兄弟子域；不使用主域名或子域后缀的宽泛放行。
同一获准域名的标准 HTTP／HTTPS 不重复确认。每次请求后清空勾选状态，后续重试仍需
一次公开页面授权；V0.43 保存的 HTTP pending 和授权字段仅作历史记录，不阻挡新请求。

（HTTP）的入口。官方佐证、核验日期和旧 URL 映射集中在核心目录；目录修订号更新为

## 网络边界

- 只执行公开 GET，不传论文、作者身份、Cookie、API Key、登录凭据或 Referer。
- 只允许标准 HTTP／HTTPS 端口。每个跳转均校验协议、凭据、主机和授权。
- 检查结构化 IPv4／IPv6、映射地址及域名解析结果，拒绝本机、私网及非公网范围。
- 系统 DNS 含 `198.18.0.0/15` 虚拟地址、且不含其他非公网地址时，自动通过
  Cloudflare DoH 查询域名的 A／AAAA。仅发送公开域名和记录类型，不发送 URL 路径、查询参数
  或作者资料。固定解析服务地址 `1.1.1.1`／`1.0.0.1`，验证 `cloudflare-dns.com` 的 TLS，
  不依赖系统 DNS 解析服务域名；拒绝服务重定向、异常响应及任何非公网结果。
  直接输入虚拟 IP、私网／虚拟混合解析、加密解析返回私网均拒绝，不因协议切换绕过。
- 解析结果必须全部可用，并通过新建客户端的 `resolve_to_addrs` 绑定连接；关闭代理与自动重定向。
- 最多 4 个候选页面（含主页）、每个响应 2 MB、每条跳转链最多 3 次跳转；
  协议重试、跳转和动态正文共用最多 24 次页面请求与 90 秒总预算。
  每次页面请求最多附加两次 DoH 查询（A／AAAA 并发），每次 32 KB、8 秒，仍受总时间约束。
- 系统 DNS 最长 5 秒、连接 10 秒、响应 20 秒。网页正文不永久保存。
- gzip 即使缺失 Content-Encoding 也可识别；传输体和解压结果分别限制为 2 MB，损坏内容拒绝。

实现参考：[reqwest ClientBuilder](https://docs.rs/reqwest/0.12.28/reqwest/struct.ClientBuilder.html)、
[encoding_rs](https://docs.rs/encoding_rs/latest/encoding_rs/struct.Encoding.html)、
[scraper](https://docs.rs/scraper/0.24.0/scraper/)。
加密解析：[Cloudflare DoH API](https://developers.cloudflare.com/1.1.1.1/encryption/dns-over-https/make-api-requests/)。

## 解析与证据

使用 HTML 解析器提取链接、还原实体及解析 base URL。保留 HTTP 和跨域指南候选，
将是否可访问交给受控读取层。中文指南（包括“征稿指南”）、拼音路径、英文指南标题、
图片 alt 和链接 title 均可识别。
正文编码按 BOM、响应头、HTML meta 顺序识别，支持 GBK／GB18030。没有编码声明且 UTF-8
失败时，仅在页面明确标记中文语言、GB18030 解码无错误的情况下推断，并在访问记录中提示。
有明确编码声明时不擅自覆盖；其余解码失败停止提取。
PDF、无正文、脚本依赖和动态接口失败均显示原因与手动粘贴入口。
动态正文仅尝试受控 GET；需要 POST 或登录的站点由作者粘贴原文。

主页仅用于发现指南。部分指南失败或仍待授权时，已取得的要求可保存为新快照，
但状态为 `requires_manual_review`，不能被当作完整期刊要求。
HTTP 获取的证据在本地记录中附加传输方式；不把网站可访问性作为内容真实性的证明。
旧快照和哈希保持不变，刷新生成独立快照。

## 访问记录与界面

每个目标的 `targets/<selectionId>/source-access/` 保存不可变开始／完成／取消记录，
并在工作区 `audit.jsonl` 追加事件。记录包括原始 URL、访问 URL、错误码、授权 origin 和快照关联。
开始记录写入失败时不会联网；崩溃中断时保留开始记录，不伪造完成状态。
最近一次完成结果可在重开目标后查看。取消额外访问不会发起请求。

主界面不解释 HTTP／HTTPS，不因 HTTP 自动展开手动粘贴。读取范围、DNS 服务及来源修正
收进默认折叠的“读取说明”。“查看访问地址与结果”仅显示响应、必要的编码提示、正文结果及
最终失败；隐藏协议切换、DNS、连接绑定和已恢复的中间失败，显示实际访问 URL。
完整诊断事件和证据传输标记仍保存在本机，不修改原始日志或历史快照。

所有新增错误码、确认、部分成功和失败文案均提供 zh-CN／en。来源原文保持原语言。
