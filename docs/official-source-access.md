# 官方来源读取与 HTTP 兼容（V0.43）

## 来源记录与网络访问

期刊画像、模型发现线索、学校政策和作者粘贴原文的来源网址接受合法 HTTP／HTTPS。
保存网址不会触发联网；不接受嵌入用户名或密码的 URL。模型 API 的远端 HTTPS 规则保持不变。

期刊要求由 Rust 受控读取。用户每次勾选授权后，HTTP 记录先尝试同路径 HTTPS。
连接、证书、超时、DNS 或 HTTP 状态失败均保留原因；不会将失败表述为“网站仅支持 HTTP”。
HTTP 访问默认关闭：只有用户对明确显示的 HTTP origin 勾选本次确认后，才可继续读取。
HTTPS 证书验证始终启用。跨域链接或重定向必须逐个确认其官方身份及精确 origin，
包括同一出版社的兄弟子域；不使用主域名或子域后缀的宽泛放行。
每次请求后清空勾选状态，后续重试必须重新确认涉及的额外访问。

## 网络边界

- 只执行公开 GET，不传论文、作者身份、Cookie、API Key、登录凭据或 Referer。
- 只允许标准 HTTP／HTTPS 端口。每个跳转均校验协议、凭据、主机和授权。
- 检查结构化 IPv4／IPv6、映射地址及域名解析结果，拒绝本机、私网及非公网范围。
- 解析结果必须全部可用，并通过新建客户端的 `resolve_to_addrs` 绑定连接；关闭代理与自动重定向。
- 最多 4 个候选页面（含主页）、每个响应 2 MB、每条跳转链最多 3 次跳转；
  HTTPS 探测、跳转和动态正文共用最多 24 次请求与 90 秒总预算。
- 单次 DNS 最长 5 秒、连接 10 秒、响应 20 秒。网页正文不永久保存。

实现参考：[reqwest ClientBuilder](https://docs.rs/reqwest/0.12.28/reqwest/struct.ClientBuilder.html)、
[encoding_rs](https://docs.rs/encoding_rs/latest/encoding_rs/struct.Encoding.html)、
[scraper](https://docs.rs/scraper/0.24.0/scraper/)。

## 解析与证据

使用 HTML 解析器提取链接、还原实体及解析 base URL。保留 HTTP 和跨域指南候选，
将是否可访问交给受控读取层。中文指南、拼音路径和英文指南标题均可识别。
正文编码按 BOM、响应头、HTML meta 顺序识别，支持 GBK／GB18030；解码失败不会以乱码继续提取。
PDF、无正文、脚本依赖和动态接口失败均显示原因与手动粘贴入口。
动态正文仅尝试受控 GET；需要 POST 或登录的站点由作者粘贴原文。

主页仅用于发现指南。部分指南失败或仍待授权时，已取得的要求可保存为新快照，
但状态为 `requires_manual_review`，不能被当作完整期刊要求。
HTTP 获取的证据附加未加密传输说明；不把网站可访问性作为内容真实性的证明。
旧快照和哈希保持不变，刷新生成独立快照。

## 访问记录与界面

每个目标的 `targets/<selectionId>/source-access/` 保存不可变开始／完成／取消记录，
并在工作区 `audit.jsonl` 追加事件。记录包括原始 URL、访问 URL、错误码、授权 origin 和快照关联。
开始记录写入失败时不会联网；崩溃中断时保留开始记录，不伪造完成状态。
最近一次完成结果可在重开目标后查看。取消额外访问不会发起请求。

所有新增错误码、确认、部分成功和失败文案均提供 zh-CN／en。来源原文保持原语言。

## 验证

确定性测试使用合成地址与响应，覆盖协议升级、逐次授权、跨域与私网重定向、混合 DNS、
页面编码、链接参数、失败状态、快照完整性以及中英文交互。
`cargo test -p manuscriptdock-desktop live_public_journal_https_probe -- --ignored --nocapture`
是单独执行的真实公开网站检查，不作为默认测试或上线可用性保证。

2026-09-05 本机实测：`jcip.cipsc.org.cn` 与 `crad.ict.ac.cn` 的系统 DNS 均返回
`198.18.x.x` 保留地址，因此在连接前被阻止，未取得真实页面正文。这可能与代理的虚拟 DNS
有关；未更改用户代理或 DNS，也未把这些地址加入公网白名单。需要正常公网解析环境才能完成
真实期刊页面获取验收。
