# ADR 0007：作者自带模型与知识体问答路由

- 状态：Accepted
- 日期：2026-08-25

## 背景

知识体需要能够接受问题和需求，但通用模型不能成为隐藏的产品后端，也不能获得整个本地
工作区。作者还需要在一家模型不可用时继续工作，并明确区分自配通用模型和 PWC 内部专业
评审 Agent。

## 决策

1. 桌面端固定提供一个主模型和两个有序备选模型，按主模型、备选 1、备选 2 自动回退。
2. 首版仅支持 OpenAI Chat Completions 兼容接口；远端必须 HTTPS，本机地址可用 HTTP。
3. API Key 存入操作系统凭据库。JSON 设置只保存槽位、提供方、地址、模型和启用状态；
   Tauri 命令永不返回明文 Key。
4. 每次调用需要作者在问答框主动提交。Rust 构建用途限定的最小知识体投影并执行唯一出网
   请求；不发送源文件或绝对路径。
5. 问题在请求前成为不可变记录，成功回答成为另一不可变记录。两者绑定具体知识体记录、
   快照和哈希，读取时复验自身哈希。
6. 模型回答不自动修改知识体。PWC 专业评审 Agent 继续属于独立信任域，不能用作者的通用
   API Key 或通用回答冒充。
7. 外部读者入口只保留数据与界面位置；认证、授权和发布链未完成前不得接收外部提问。

## 后果

- 作者控制提供方、费用和传输时机，并能使用本机兼容服务。
- 供应商故障可以通过明确的有限回退链恢复；不会进行无界重试。
- WebView 会短暂承载作者正在输入的 Key，但不具备读取系统凭据或任意出网的能力；持久化、
  取用和请求由 Rust 负责。
- 问答成为知识体演化的可验证输入，而不是与版本和来源脱节的聊天历史。
- 完整实时流式响应、供应商专用协议、OAuth、费用预算与外部公共问答留待后续决策。
