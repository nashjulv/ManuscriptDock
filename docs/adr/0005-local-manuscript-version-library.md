# ADR 0005：本地论文版本库

- 状态：Accepted
- 日期：2026-08-24

## 背景

单一不可变源快照可以保证导入安全，但无法支持作者持续修改、对比、恢复和返修。直接依赖外部 Git 会暴露不适合普通作者的术语，也不能统一处理 DOCX、PDF 和 TEX 的确定性结构比较。

## 决策

ManuscriptDock 在 Rust 可信层维护应用专用的内容寻址版本库：

- 首次导入形成 v1；
- 真实内容变化形成连续不可变版本；
- SHA-256 相同则拒绝重复版本；
- 每个版本记录父版本和来源；
- 恢复旧版必须创建新版本，永不移动或覆盖历史；
- 当前稿件分析和投稿检查始终绑定清单中的当前版本；
- WebView 不获得版本文件路径或文件系统权限；
- schema v2 兼容读取 v1 工作区，并在首次新增版本时迁移。

## 后果

作者得到类似本地代码仓库的可靠历史，但界面只需要理解“版本、比较、恢复”。代价是应用需要承担清单一致性、跨平台只读权限、磁盘占用和未来迁移策略。格式转换继续作为派生输出，避免污染作者修订谱系。
