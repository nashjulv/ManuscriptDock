## 修复

- 中文界面不再自动设置“只接受中文稿件”的投稿硬条件；默认不限，用户显式选择的投稿语言仍生效。内置目录增加中文检索映射和 eISSN 搜索，进入已知目标流程即显示目录。目录仍只有三本可生成试点，不能据此宣称支持中文投稿期刊。
- 恢复三层同心圆候选选择，与期刊卡片联动。圆环表达推荐角色，不代表录用概率。
- 每个项目／目标有独立、真实的可编辑本地目录，包含原稿副本、投稿材料和作者工具。提供目录树、图标／列表、文件拖入、目录内移动、文件管理器入口、返回应用刷新和手动刷新。
- 外部编辑与内部快照分开：点击“按所选附件用途加入投稿包”后创建核验快照，修改后重新加入可替换该用途同名文件的活动版本，旧快照仍保留。原始稿件和旧导出不会随文件整理被改写。
- 目标期刊要求、必需／建议、待补状态、计划文件、来源和核验日期在材料页展示。官方来源通过 Rust 登记 URL 校验后打开系统浏览器。
- 一键生成现有本地模板草稿，生成结果写入新的 `drafts/<版本>` 子目录，不覆盖编辑过的文件。当前不包含 LLM 调用；科研结论、作者贡献、伦理、经费和利益冲突事实须作者核对。
- 修复推荐转入目标时丢失文章类型，以及 DOCX 原稿的可编辑替代稿未被采用的问题。预告匿名稿、标题页和研究亮点文件时不再等到材料齐备才列出。
- 修复异步目标／准备视图过期响应覆盖当前状态，保留材料加入后的目录浏览状态。

## 使用边界

目录中的文件不会仅因出现而自动成为可投稿材料。选择用途并加入后，编译器按目标规则生成投稿快照；目录结构是整理空间，出版社 ZIP 仍采用受控生成结构。删除整理目录中的副本不会删除已经确认的历史快照。生成草稿不代表满足正式投稿要求。

Internationalization review：检查 `zh-CN`／`en` 的目录操作、状态、目标要求、来源入口、生成说明、同心圆可访问名称、参数化错误和文件大小格式。科研原文和实际文件名保持原语言；出版社模板仍使用英文，未接入 LLM。
