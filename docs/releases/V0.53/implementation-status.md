## 已实现

- 核心改为两项本地任务：推荐期刊、按已知目标整理投稿包；删除远程模型、知识体、PWC、官网抓取、存证和旧修订台运行入口。
- 新建版本化 `ProjectStore`：DOCX 在临时项目目录内复制并复核大小／哈希，完整 manifest 落盘后一次改名提交；材料读取一次后写入项目快照，安全／匿名检查只针对该快照，失败会清理本次材料目录和原子写临时文件；另有 revision 并发检查、进程内 mutex 与跨进程文件锁、坏记录隔离、最近任务、材料副本和生成包重启恢复。
- `open_project`、推荐、选刊、事实更新、附件、生成和导出均携带 UUID `requestId`。同请求在进程内并发只执行一次，成功响应原子留档并可跨重启复用；请求标识不能跨操作复用。前端对不确定失败保留原 requestId，成功后才轮换。
- 修改操作先持久化 queued job 并立即返回 jobId，再由 Tauri 后台工作线程执行文件解析、旧任务复制、推荐、选刊、事实更新、附件、生成和导出。running／终态及类型化结果写回同一 job，按顺序广播 `manuscriptdock://job` 事件；前端以事件更新为主、`get_job` 查询为丢事件／重启恢复兜底，并在任务进行中提供双语取消操作。`cancel_job` 会阻止已取消任务写入 succeeded 终态且不删除既有输出；启动时把遗留 queued／running 状态恢复为 interrupted。当前取消在动作开始和终态提交处生效，解析器／编译器内部的细粒度协作式检查点仍待补齐。
- 首页只读列出可安全识别的 V0.52 DOCX 任务；作者明确点击后才从旧 `workspace/` 创建 `workspace-next/` 新副本。迁移映射记录 oldProjectId、newProjectId、sourceHash、completedSteps 和 schema，可从预留映射恢复并保证重复打开复用同一项目；安全匹配当前目录的目标、旧结构核对中的标题／摘要／作者（保持未确认）及哈希有效的普通附件会一并复制。损坏记录、危险相对路径、链接和哈希不符附件被隔离，合成测试确认旧原稿、manifest、核对记录、目标和附件字节不变。新产品只接受 DOCX，因此旧 PDF／LaTeX 显示为不可恢复，不执行有损转换。
- 原生文件／文件夹／导出目录选择均返回短期 token，WebView 不接收输入路径或内部 staging 路径。文件夹只读直接普通文件并拒绝符号链接，多 DOCX 必须由作者选择，未分类附件默认不进入投稿包。
- DOCX 预检限制条目数、展开量和 XML 大小，拒绝路径穿越、加密和高风险嵌入对象，枚举外部关系且不访问网络。
- 内置 12 本计算机／AI 期刊目录；其中 3 本标为“试点规则”，另外 9 本只进入待补证池，不能被选择为具备专属生成能力的目标。已在浏览器中逐项读取三本官方 Guide for Authors 的标题页、摘要、关键词、匿名评审、Highlights、利益冲突、经费、数据、CRediT 与生成式 AI 披露章节，并记录[核对矩阵](journal-rule-audit.md)：AI 关键词 1—10，ESWA/KBS 1—7；三本摘要上限 250 词，Highlights 建议 3—5 条且每条不超过 85 字符；ESWA 为双匿名，AI/KBS 为单匿名。规则使用公共父包与各刊子包、类型化数量／长度约束；目录与规则由 `2026-09-14.2` Ed25519 签名 manifest 绑定内容哈希和许可说明，验签、未知父规则、继承循环或哈希失败即停止使用。
- 硬条件先过滤，未知不当作通过；推荐页可显式选择 SCIE／Scopus 收录硬条件和“优先首轮决定较快”的软偏好。最多返回 3 本可选择结果；候选卡片展开后显示逐项通过／不通过／未知的约束解释、选择后需要完成的准备任务、原因、风险和证据来源，待补证候选单列。当前试点目录没有已核实的首轮决定数据时，只提示风险，不用缺失值制造速度优势。
- 准备清单由 Rust 从规则和当前事实一次投影，并为每个缺项／建议项／就绪项返回可展开的官网证据和逐文件 PackagePlan。摘要、关键词、作者、单位、邮箱、利益冲突、经费、数据声明、Highlights、CRediT 和条件性生成式 AI 披露均可在双语界面核对；作者确认生成带值、证据、时间和上下文哈希的独立 AuthorDecision。数量、字符或词数不满足规则时不会变成 ready；字段、规则或目标变化会使旧决定失效并阻止旧生成结果。
- 投稿包默认保留原稿字节，不宣称通用自动排版或自动匿名化。ESWA 的双匿名规则会阻止缺少匿名稿的 final；作者明确选择并核对匿名 DOCX 后，Rust 会在全部 XML／关系部件中查找与已确认作者姓名、单位和邮箱完全匹配的内容，事实变化后重新扫描，生成前再次检查。已知命中会阻止正式包并给出不含原值的双语类别提示；通过当前检查后，该文件原样替代实名源稿进入 `submission/manuscript.docx`，实名源稿不进入出版社 ZIP，并从已确认事实生成独立标题页。此扫描不识别别名、自引、图片文字或语义线索，不能证明完全匿名。已确认的利益冲突会生成出版社用 Word，满足规则且经确认的 Highlights 才生成出版社用 Word；作者工具另含标题页、投稿信、声明草稿、字段 XLSX 和合规 DOCX。生成前后均复核快照大小／哈希；同名附件使用稳定后缀，不能覆盖主稿或彼此覆盖。生成或导出在复制、校验、时间记录或原子改名之前失败时会清理本次临时目录；导出回执绑定 requestId，不确定重试先恢复回执而不重复导出。
- 生产 CSP 不允许 localhost 或 WebSocket；开发 CSP 单独允许 Vite。产品名和 Bundle ID 保持稳定，显示版本为 `V0.53`，包版本为 `0.53.0`。
