# V0.60 实现与验证

交付分支为 `feature/submission-assistant`。分支重命名时保留了 `a3ce942` 基线与完整工作区改动，旧本地分支名称已移除。本轮按用户要求更新文档并通过此分支提交、推送；具体提交与远端同步状态以 Git 记录为准。未发布安装包或部署。

## 本次累计变更

- 投稿目录的图标／列表浏览、目录内拖动、外部文件导入与刷新，按所选文件夹／文件位置创建目录。
- 投稿语言与界面语言解耦，修复中文界面目标期刊缺失；恢复同心圆候选显示，展示目标要求与官方原文链接。
- 根据目标要求列出缺失材料，逐项／批量生成模板和本地草稿；已有文件不能重复生成，已有模板不能重复生成模板。
- 右上角单一材料状态标签，编辑后重新检查、作者确认并保存快照；文件或事实变化后撤销旧确认的适用性。
- 固定首页按钮及未保存输入提醒。
- 可选 AI 投稿信／Highlights 起草、单项语义检查、一致性检查、来源预览与逐次同意、结果失效校验和使用记录。

实现内容见[可选 AI 材料助手](../../optional-ai-assistance.md)。首页文案改为“基础功能无需配置模型 · AI 辅助按需启用 · 原稿始终保留”；顶部与侧栏使用“本地优先”，不再笼统声称论文内容不离开设备。

## 已验证

`npm run check` 通过：69 项前端测试、47 项 Rust 测试、TypeScript、生产构建、Rust 格式与 Clippy；`git diff --check` 无问题。

- 前端双语测试覆盖设置保存不调用模型、逐次预览与同意、防止重复请求、草稿单独采用、过期结果禁用、限流失败、不将无问题建议当作确认、历史及全部新增错误码。
- Rust 合成 DOCX 测试覆盖来源引用、已有文件拦截、模板修改失效、事实变化失效、重复采用拦截、保留原稿、待核对状态、Highlights 数量限制、项目调用锁与审计导出。
- Rust 真实回环 HTTP 模拟服务验证成功响应、伪造引文拒绝、认证失败、限流和重定向拒绝，确认没有自动重试或附带无关凭据。没有调用真实收费模型。
- 浏览器使用真实 React 页面、合成 IPC 数据验证设置→资料预览→同意→模型建议→保存待核对草稿→已有文件禁用生成→一致性检查。1280 与 760 像素视口，中文和英文，无控制台错误与横向溢出；截图已人工检查。
- 当前环境未提供独立 Browser 插件入口，按 frontend-testing-debugging 技能使用本机 Playwright/Chromium。模拟 IPC 的浏览器验证不等于原生 Tauri 或真实服务验收。

## 验证边界

真实外部服务、系统凭据库读写和 Windows 原生界面未在本轮实际调用验收。运行时具备对应实现，但模型兼容性与内容质量仍需使用者选定服务后验证。单次调用前会告知实际发送资料、模型及估计 token，不虚构费用。AI 的准确性、政策遵循和投稿就绪状态仍由作者核对。

## Internationalization review

检查 zh-CN 与 en 的首页、侧栏、顶部设置、AI 表单、资料预览、同意、结果与引用、失败状态、历史、材料状态及响应式布局。所有新动态错误使用稳定代码并配有双语映射；模型建议要求同时返回中英文，引用与作者文本保留原文。英文投稿草稿与机器可读审计 JSON 不自动翻译研究内容。新增版本身份为“投稿舱 ManuscriptDock V0.60”，安装元数据为 `0.60.0`，产品标识不变。
