## 本版变更

- 原生文件和文件夹入口将 PDF 与 DOCX 都识别为论文主稿；WebView 仍只获得短期 token。PDF 会先校验文件头、加密标记和大小，再在 Rust 中提取有限文本用于标题、摘要、关键词和语言初值；不从 PDF 推断作者身份。
- PDF 和 DOCX 都会创建带大小与 SHA-256 的不可变本地源快照。PDF 文本不可提取时保留明确警告或类型化错误，不调用远程模型、OCR 或网络服务。
- 材料文件夹现在是长期项目工作区：同一规范化文件夹重复打开时复用同一个项目 ID；更换主稿会新增不可变源稿版本，未变化附件不会重复复制。文件夹绑定与真实路径只由 Rust 保存，WebView 仅接收短期 token 和安全显示字段；导出默认在项目文件夹中创建新的版本化 `ManuscriptDock-*` 子目录，不覆盖输入。
- PDF 项目可完成期刊推荐，并可生成保留原 PDF 字节的草稿检查包。三本试点期刊的正式包需要作者明确选择、核对的可编辑 DOCX；应用不把 PDF 反向转换、改扩展名或伪装为 Word 文件。双匿名目标仍优先使用通过当前身份完全匹配检查的作者核对匿名 DOCX。
- 最近任务可从首页移除并在“已移除任务”中恢复。实现只维护 `recent-hidden.json` 隐藏索引，不删除项目 manifest、源稿快照、材料、生成包或用户已保存到外部位置的导出。
- 早期版本尚未上线，旧任务数据不再需要：V0.54 已移除首页“早期版本任务”、旧根扫描、导入命令、迁移记录和对应领域模型／测试。应用不读取或迁移旧任务，也没有删除磁盘上已有文件。
- 推荐偏好页默认只展开投稿语言、文章类型和研究关键词；投稿语言默认跟随客户端界面语言，在作者手动修改前随界面语言切换，不从原稿语言推断。当前内置目录没有满足简体中文硬条件的已核验可生成目标时，结果页解释覆盖缺口并提供需作者点击的“改为 English 并重新推荐”，不静默放宽。文章类型和关键词优先使用论文解析值。APC／币种、开放获取、SCIE／Scopus 收录和首轮决定速度折叠到“更多设置”。币种默认 USD，首轮决定速度偏好默认开启；开放获取和收录属于硬条件，不在没有作者依据时自动勾选。
- 新增的 PDF 状态、可编辑主稿要求、移除／恢复操作和失败消息均提供 `zh-CN` 与 `en` 文案。
- 产品显示版本递增为 `V0.54`，包版本为 `0.54.0`；产品名、应用标识和 Bundle ID 保持稳定。
