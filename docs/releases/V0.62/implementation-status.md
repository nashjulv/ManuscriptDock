# V0.62 实施记录

## 调整与修复

- 保留推荐期刊、整理投稿包及材料检查等主要功能。恢复原 UI 的浅灰底、细分隔线和黄绿色主按钮（#A6CE39），移除渐变和装饰性卡片阴影。
- 全局使用 PingFang 优先的系统字体，正文 300、标题与控件以 400 为主。统一 Meta / Body / Section / Page 四种语义字号，Aa 增加第四档“特大 / Largest”，原有偏好继续兼容。
- 材料清单主稿项增加“选择 DOCX”和“检索目录内 DOCX”。检索包含子目录及大小写扩展名，由用户选择文件并确认后关联；后端仍使用现有受限路径、版本检查、不可变副本和匿名稿检查流程。
- 原先显示的 `submission/manuscript.docx` 是投稿包中的目标文件名，不保证该文件已经存在。界面现明确区分目标路径、候选文件和已关联主稿。目录中出现 DOCX 不会自动标记完成，也不会自动匿名化。
- 修复打包客户端 Logo 使用开发路径的问题，以及特大字号下主稿确认复选框被通用输入框宽度撑开的布局问题。
- 显示版本 V0.62，软件包版本 0.62.0，保留 ManuscriptDock 标识。

## 验证

- 前端 77 项回归通过：中英文四档字号、保存恢复、材料生成与检查原流程、DOCX 子目录与大写扩展名检索、取消、空结果、作者确认、导入失败重试。
- Rust 49 项回归通过：含四档偏好持久化、DOCX 候选不自动完成、显式关联与原文件保护、匿名稿身份信息阻断、现有材料与导出流程。
- TypeScript 检查、生产前端构建、macOS debug 应用打包、Rust fmt、Clippy 和差异空白检查。
- 原生 V0.62 窗口检查：Aa 四档选项、中文与英文首页、特大字号材料页、实际目录内 DOCX 检索与候选选择。未代替作者确认真实稿件；文件关联与打包链路使用合成用例覆盖。
- Rust 回环测试需要沙箱外绑定 127.0.0.1；普通沙箱运行会因权限失败，获准后完整回归通过。清除了前一版 PDF 回归测试中 Copy 枚举的多余 clone，Clippy 通过。

## Internationalization review

检查 zh-CN 与 en 的四档字号名称、文件位置说明、主稿候选、作者确认、无结果和错误恢复。新增文案均经现有 i18n 辅助函数成对提供；后端复用稳定错误码，不新增未翻译的运行时错误。文件名、源稿和导出排版不翻译、不改写。未验证 Windows 字体回退的实际窗口效果；macOS 原生验证不等同于发布安装包或真实出版社投递验收。
