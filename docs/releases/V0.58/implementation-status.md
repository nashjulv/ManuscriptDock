## 使用流程

1. 点击材料状态按钮，在外部应用编辑模板或草稿并保存。返回投稿舱或点击目录刷新后，文件内容哈希变化会显示“已修改 · 待检查”。生成时记录基线哈希，不依赖修改时间判断完成度。
2. 点击“检查并确认完成”。本地检查 DOCX 可读性、已知待填占位符、空正文、标题页通讯邮箱，以及规则包中可执行的条目数量、每项长度和字数限制。检查结果中英文成对返回。它不验证科研事实真实性，不覆盖全部排版和语义要求。
3. 检查通过后，作者勾选期刊要求核对和内容真实性确认，再点击“确认完成并保存快照”。文件与上下文若在检查后发生变化，则拒绝确认并要求重查。
4. 确认记录绑定文件哈希、来源路径、目标期刊、规则、原稿与事实信息；保存独立 DOCX 快照和确认记录，显示单一“已确认”状态。重复确认相同版本复用快照。
5. 投稿包复制当前有效的确认快照到对应投稿文件位置，并记录确认依据。已确认的对应材料要求进入就绪状态；未填写的其他稿件信息和要求仍需补齐。
6. 后续再次修改文件或投稿上下文，当前状态回到待检查，旧快照保留但不再自动用于当前投稿包。删除文件后回到缺失状态。旧导出文件不会被更改。

旧版模板没有生成基线时不会猜测其修改历史，仍可直接检查并确认。作者自行加入文件需使用材料清单所列的对应文件位置，系统不会凭任意文件名推断其用途。
