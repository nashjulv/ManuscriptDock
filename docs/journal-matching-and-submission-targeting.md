# 期刊匹配与投稿目标推荐

## 产品定位

期刊匹配是“版本”与“存证”之间的本地决策阶段。它不回答“哪本期刊一定录用”，而是基于当前论文版本、作者确认的投稿偏好和可核验的期刊目录快照，给出值得优先核对的投稿目标。

首版聚焦计算机与人工智能，固定输出国内 3 家、国际 3 家。作者修改学科方向、文章类型、语言、目标策略或开放获取偏好后，系统重新计算并形成新的推荐运行记录，旧记录不会被覆盖。

## PWC 方案的单机化裁剪

PWC 的完整对象是“稿件版本 × 期刊版本 × 机构规则版本 × 数据快照”。ManuscriptDock 首版保留版本绑定、规则与模型分离、可解释评分和重复计算四项原则；机构/学校规则尚未配置时显示 `not_configured_excluded_from_score`，不虚构规则，也不把缺失项当作零分。

首版不调用大模型、不运行时抓取网站、不发送论文。AI 仅作为后续候选召回和语义辅助能力，输出仍需经过确定性评分、来源校验和作者确认。

## 推荐流程

1. 读取当前不可变论文版本的标题、摘要、章节、图表、参考文献和结构警告。
2. 本地关键词规则推断计算机/AI 子方向；作者可覆盖推断结果。
3. 从内置、经核验的候选快照召回国内与国际期刊。
4. 分别计算主题范围、文章类型、内容完备度、语言、目标档位和开放获取偏好。
5. 国内、国际分别排序并显示前 3 家，同时展示分项分、依据、排名来源和期刊主页。
6. 作者调整条件后重新计算，保存新的 `JournalRecommendationRun`。

## 确定性评分 V1

| 维度 | 权重 | 含义 |
| --- | ---: | --- |
| 主题与办刊范围 | 35% | 当前研究方向与候选期刊领域标签的关系 |
| 文章类型 | 15% | 研究论文、综述或应用型稿件是否在候选范围内 |
| 内容完备度 | 20% | 标题、摘要、关键词、章节、图表、参考文献和篇幅的结构性准备程度 |
| 投稿语言 | 10% | 作者语言偏好与期刊语言是否一致 |
| 目标策略 | 15% | 冲刺、均衡或务实策略与公开目录档位的关系 |
| 开放获取 | 5% | 无偏好、优先或必须开放获取 |

综合适配分范围为 0–100，仅用于当前候选集内排序，不是录用概率、影响因子预测、同行评审结论或学术质量裁定。

## 数据来源与版本

首版目录版本为 `computer-ai-2025.1`，排名核验日期为 2025-04-16。

- 国内排名依据：[CCF 中国计算机领域高质量科技期刊分级目录（2025）](https://www.ccf.org.cn/ccftjgjxskwml/)。目录明确说明国内 T1/T2/T3 与国际 A/B/C 是两套独立目录，不进行等级等同。
- 国际排名依据：[CCF 推荐国际学术刊物目录——人工智能](https://www.ccf.org.cn/Academic_Evaluation/AI/)。
- 办刊范围、语言和投稿类型以各期刊官网为一等来源，例如[软件学报](https://jos.org.cn/)、[计算机学报](https://cjc.ict.ac.cn/)、[JMLR](https://www.jmlr.org/)和[TACL](https://transacl.org/)。

候选池仅用于产品验证，并不声称覆盖所有期刊。目录更新必须形成新版本，历史推荐继续引用原目录版本。

## 数据合同与信任边界

每次运行固定记录：`runId`、稿件版本和内容哈希、算法版本、目录版本与核验日期、输入偏好、推断主题及依据、完备度、两组推荐及分项得分、来源 URL、学校规则状态、限制说明和外部传输状态。同一稿件版本与同一组条件产生稳定的运行 ID；条件变化产生新的 ID。本地文件位于工作区 `analysis/journal-match-{runId}.json`，审计日志记录 `journal_recommendations_computed`。

- 不保证录用，不自动投稿，不把推荐顺序包装成“最佳期刊”。
- 投稿前必须访问期刊官网核验最新范围、格式、费用、周期和伦理政策。
- 不抓取或复刻付费商业榜单，不以搜索摘要作为正式证据。
- 不把国内 T1/T2/T3 映射成国际 A/B/C。
- 作者未配置学校/机构规则时，该维度完全不参与评分。
- 未来联网更新、模型调用和 PWC 机构规则同步必须在执行前说明对象、范围和版本。

## MVP 验收

- 任意可提取的当前版本均返回国内 3 家、国际 3 家。
- 视觉、自然语言处理等方向调整会改变候选排序。
- 相同输入重复计算结果稳定；不同偏好生成不同运行 ID。
- 所有得分均在 0–100，界面明确提示“不是录用概率”。
- 计算、保存和审计均在本机完成，外部传输标记为 `not_performed`。
