## 结论与统计口径

建议采用“入口可点击，点击后解释并引导补齐前置条件”的统一交互。当前问题不仅包括按钮置灰，还包括未满足条件时整个上传入口消失。

本次扫描非测试 TSX 文件，发现 81 处 `disabled` 属性，其中 62 处位于按钮或操作组件，另 19 处涉及输入框、选择框、字段组或属性传递。这是源码位置数，包含共用组件、重复入口、动态列表和执行中锁定，**不等于 62 个独立功能需要修改**。以下按用户操作归并，列出 22 组引导场景，并补充相关非按钮控件与隐藏入口。

证据分为两类：用户截图已经证实“未选目标期刊时，上传资料页没有上传按钮”；其余项目来自当前源代码的渲染和禁用条件审查。本轮没有逐项运行桌面操作，不把代码推断记作新的实测结果。

## 一、优先处理投稿主流程（P0）

| 编号 | 页面与操作 | 当前前置条件 / 表现 | 建议点击行为 |
| --- | --- | --- | --- |
| A01 | 目标期刊：生成推荐，包括使用学校要求生成推荐 | 准备期限必须满足当前校验；学校要求可以不填，但填写后至少 40 字。按钮同时受执行中状态限制 | **本页定位**：展开“学校、用途和准备期限”，定位期限或学校要求文本并说明原因。不要误将作者姓名、学校、专业变成必填项 |
| A02 | 目标期刊：设为主选、设为备选 | 推荐必须属于当前稿件版本；必须确认本次推荐的文章类型 | **本页定位**：版本过旧先定位“生成推荐”；版本有效但未确认则定位并高亮文章类型确认框。不能用勾选框替代重新推荐 |

| A07 | 投稿资料：上传原始图件、可编辑表格、期刊要求文件、通用文件，以及“为此要求添加文件” | 上传依赖当前版本目标和有效官方要求；条件不满足时按钮禁用，清单为空时上传卡片甚至不渲染 | **跨页提示**：“需要先到‘目标期刊’确认本版本的主投期刊并取得有效官方要求。”提供“前往目标期刊”。根据实际缺项缩短提示；保留可发现的上传入口与说明，不能只留下空白 |

“有效官方要求”在当前前端判定中包括：要求快照版本满足条件、状态不是待人工复核、要求非空、仍在有效期内；目标还必须对应当前稿件版本。不能只判断“曾选过期刊”或“曾读取成功”。

| B08 | 本地存证：创建存证 | 当前页面具备检查结果后，仍需作者确认 | **本页定位**到作者确认框；缺检查结果时保留现有前往检查的入口，并解释先检查的原因 |
| B09 | 投稿包：记录投稿 | 作者必须确认已经完成外部投稿 | **本页定位**到确认框，说明“仅在实际完成投稿后登记”。导出完成不代表已投稿，不能自动勾选 |

声明核验表单还有浏览器原生校验，例如要求名称、来源网址、原文、作者备注及文件数量。它们目前并非由缺字段导致按钮置灰，应统一错误定位体验，但不要误记为现有禁用条件。

## 三、工作区与高级能力（P2）

| 编号 | 页面与操作 | 当前前置条件 / 表现 | 建议点击行为 |
| --- | --- | --- | --- |
| C01 | 未创建工作区时进入侧栏功能；保存并开始 / 创建独立工作区 | 导航直接禁用；创建操作要求已取得文件选择记录 | **本页引导**到选择稿件 / 创建工作区区域；说明先导入稿件。创建按钮的缺选择记录条件也要有错误恢复路径，而不只是静默置灰 |
| C02 | 已归档工作区：打开论文 | 已归档条目不能直接打开，需从“管理”中恢复 | **本页引导**：展开该条目管理菜单并突出“恢复到最近工作区”；不在用户仅点击论文时自动恢复归档 |
| C03 | 模型设置：保存设置（全局弹窗与知识体面板两处） | 启用的模型项必须补齐服务名称、接口地址、模型名和可用密钥；文档网址、清除密钥等状态也影响保存 | **同一弹窗/面板内定位**到第一个有问题的启用项及字段，说明补齐或停用该项。不要求补齐未启用项，不回显已保存密钥 |
| C04 | 知识体：完成/更新知识体 | 需要学科、全部候选条目核验、最终作者确认 | **本页定位**：先补候选核验、学科与最终确认；候选为空时解释需要重新提取或核验结构，不跳到不能勾选的最终确认框 |
| C05 | 知识体：询问知识体 | 需要知识体记录，已配置模型时还需问题文本 | 缺知识体时引导完成知识体；缺问题时聚焦输入框。未配置模型时现有“打开模型设置”行为已经可用，应保留 |

以上共 **22 组引导场景**。同类多入口合并统计，实施与测试时仍需覆盖各个实际入口。

## 四、非按钮控件与隐藏入口需一起处理

| 控件 / 入口 | 当前情况 | 建议 |
| --- | --- | --- |
| 材料目录中的“纳入”复选框 | 历史版本、不同目标/要求、没有对应上传项、后续阶段或不适用材料不能直接纳入 | 为点击标签或旁边说明提供原因与解决入口；可复用历史材料走复用流程，不能简单解除禁用 |
| 投稿包文件中的“纳入”复选框 | `inclusionAvailable=false` 时禁止纳入 | 展示该文件不能纳入的具体原因；必要时前往材料/要求核验。不能自动改变材料适用性 |
| 知识体最终作者确认框 | 候选条目未全部核验时禁用 | 点击标签/说明引导到第一个未核验候选；完成按钮也必须使用相同条件顺序 |
| “不适用”选项 | 当前规则不允许声明不适用时禁用 | 明确解释规则约束；不能给出“补写原因即可放行”的错误引导 |
| PDF 等不可编辑修订字段 | 源文件类型或字段能力限制 | 说明只读原因，并指向实际支持的关联源稿/修改稿流程；不直接开放原稿编辑 |
| 清除已存 API Key | 从未保存 Key 时禁用 | 显示“尚无已保存密钥，无需清除”，这是无操作对象，不是漏做了上一步 |
| 知识体双体 / 网络视图 | 分别需要至少 2 / 3 个知识体；当前禁用提示提到关系，而实际条件检查数量 | 提示应对应真实数量门槛；只有确认存在可执行的建立流程后才给跳转，不能虚构页面或暗示已有完整能力 |
| 上传卡片、声明计划为空 | 前置条件不足时内容可能整体消失 | 保留稳定入口或空状态，展示“为何尚不能操作”和明确下一步；已完成目标核验且确实无此要求时，应解释无需上传，不能冒充缺失要求 |

用户截图属于最后一行：页面已进入“上传资料”，但没有目标期刊导致上传项为空。这里仅取消按钮的 `disabled` 不会产生任何可见入口，必须单独处理空状态。

## 五、统一点击规则

1. **本页前置条件**：保留正常可点击按钮；点击后切换必要的子标签、展开折叠区域，再滚动、聚焦并高亮具体字段/确认框。旁边用一句话说明缺什么；高亮不能仅靠颜色。
2. **跨页前置条件**：弹出简短说明，列出目标页面和待完成操作，提供“前往 XXX”与“暂不处理”。点击前往后保留当前稿件上下文，定位到具体项目，不只打开页面顶部。
3. **多条件缺失**：显示简短待办列表，优先解决依赖链最前面的条件。切换页面前保留尚未保存的输入；不能丢掉表单后才提醒保存。
4. **补齐后由用户重试原操作**：可以提示“已满足条件，可继续”，但不能自动执行网络读取、设置目标、导出、存证或投稿登记。授权与作者事实确认仍由本人完成。
5. **状态变化时重新判断**：按钮点击时检查当前稿件版本、目标和要求状态；后端校验仍保留。若检查后状态又变化，错误也应给出对应恢复入口。
6. **执行中防重复操作单独处理**：读取、保存、删除、恢复、导出等进行中保留锁定和进度反馈。它们没有需要用户补齐的前置步骤，不应点击后乱跳到其他页面；此前修复的读取中许可状态保持不变。
7. **稳定文案**：主按钮尽量保持操作名称，点击提示解释缺项；不要仅把“设为主选”改成“先核对……”后仍禁用。用一致的目标命名，避免把目标期刊称为多个不同页面。

| 上传前缺目标 | 需要先到“目标期刊”选择当前版本的主投期刊，才能按该刊要求上传资料。 | Select a primary journal for the current version in Target Journal before uploading journal-specific materials. |

## 六、原定实施顺序与验收清单

建议先完成统一的“判断缺项—本页定位 / 跨页说明”能力，再逐批接入，而不是每个按钮各写一套弹窗。

- **第一批 P0**：目标选择、官方读取/粘贴、进入材料、上传入口与空状态、导出阻断引导，覆盖当前用户实际遇到的主流程卡点。
- **第二批 P1**：材料复用、声明与适用性核验、结构核验、源稿关联、版本修订、存证、投稿登记。纳入相关非按钮控件的原因说明。
- **第三批 P2**：导入前导航、归档恢复、模型设置、知识体完成/问答与视图可用性说明。

实施时每个场景至少验收：

- 条件缺失时按钮可聚焦、可点击，实际定位到正确字段；折叠区和子标签也能打开。
- 跨页提示写明缺项，确认跳转后保持原稿件并定位正确任务；取消不改变工作区。
- 条件齐全时正常执行；多个缺项、旧版本、要求过期、候选为空、没有可复用文件时不出现死循环。
- 仅点击被引导按钮不产生业务写入或外部读取，不自动勾选授权/作者声明。
- 连续点击不产生重复请求；执行中、完成后与失败后的状态保持一致。
- 无目标上传页与“有目标但确实无该项要求”的空状态有明确区别。
- zh-CN/en 均覆盖提示、按钮、动态原因、聚焦说明与失败状态；键盘可操作，提示可由屏幕阅读器读出，并支持减少动效。
