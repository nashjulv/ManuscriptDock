# 投稿舱 ManuscriptDock V0.43 开发 MVP 完成状态

- 状态：M0–M9 开发完成，可用于本机技术与用户流程验证
- 日期：2026-09-04
- 发布性质：开发构建，不是已签名的公开安装包

## 已完成闭环

1. 用户通过系统文件选择器选择 DOCX、PDF 或 TEX；Rust 返回安全元数据和一次性标识，
   WebView 不获得文件路径。
2. Rust 在应用数据目录创建工作区，复制、计算 SHA-256 并设为只读；源稿件不被覆盖。
3. 每次分析前再次验证快照大小和指纹，拒绝被修改的快照及路径穿越记录。
4. Rust 确定性提取标题、作者、摘要正文候选、关键词、章节、图表、参考文献和常见投稿
   声明；PDF 先完成文档及页面分类，再优先使用布局感知解析恢复 CID 字体、多栏顺序、
   标题层级和表格，最后回退增强字体映射与基础内容流。分类、置信度、表格页、多栏页和
   缺失对象候选不会因回退而丢失，混合或异常编码 PDF 只把对应页面路由到补充识别。
5. Rust 验证 2 套基础包和 16 套可选增强包的 Ed25519 数字签名，按继承关系执行用户
   选择的中国标准、国际伦理、出版商和研究报告检查，并区分通过、建议、阻断和作者确认。
6. 每篇论文现在具有本地不可变版本库：支持连续版本、SHA-256 内容去重、父版本关系、
   版本说明、确定性结构比较，以及把旧稿恢复为新版本；既有 schema v1 工作区可兼容读取。
7. 每次检查生成新的本地 JSON 报告与自包含 HTML 预览快照，并追加审计事件。
8. 桌面 UI 采用“概览—目标期刊—投稿资料—检查与修订—投稿包”五个用户主任务；版本、
   存证与个人知识体收为高级功能，证据面按需展开。选择主目标并取得有效官方要求后，资料
   清单才按该出版社组织；检查或修订完成后直接进入投稿包。继续保留灰绿视觉、`#A6CE39`
   主色与苹方字体。
9. 目标步骤已经支持组合标准级和出版商级规则；Elsevier、Springer Nature、Wiley 和
   IEEE 规则还会生成去重的结构化投稿要素，并保留规则来源与完整性。具体期刊 A 级
   差异包与自动排版仍保持显式未实现。投稿包视图只展示真实生成物，知识体
   视图持续汇总不可变原稿、确定性结构、规则证据和版本状态。
10. Rust 可信核心已经提供 `AcademicKnowledgeBodySnapshot v2`：稳定身份与版本、知识边界
    与证据、能力契约、交互运行时、验证权利与信誉五部分拥有明确边界。十类论文对象、
    Claim 内部语义约束、独立 `AIReviewReport` 版本链和八类跨体声明协议继续保留；模型
    是可替换运行时，ReputationRecord 独立于不可变内容演进。schema v1 记录保持可读。
    当前工作区只生成真实的本地单体快照，不虚构 AI 审核或跨体关系；桌面主操作区以动态
    点云、Claim 十二面体和五个可交互服务节点呈现单体，并按对象数量渐进开放两体和关联网络。
11. 当前版本的结构、检查、存证、投稿和知识体记录可以在重启后恢复。存证记录绑定稿件
    指纹与检查报告并自带可复验 SHA-256；投稿交付包可导出到作者选择的文件夹，作者在
    外部系统完成投稿后可登记目标与回执；投稿后可固化绑定完整链路的知识体记录。
12. 知识体固化要求作者从 12 项双语学科索引中确认主要学科，形成可版本化的
    `ClassificationAssignment`。最终页完整显示覆盖分类、快照、存证和投稿引用的 64 位
    SHA-256；重新分类生成新的不可变记录，既有无分类记录可兼容读取并补充分类。
13. 知识体主操作区的空间图下方已提供作者问答台和模型设置，不依赖展开证据面板：固定一个主模型与两个备选模型，Key
    使用系统凭据库，Rust 按顺序调用 OpenAI 兼容接口。最小投影包含能力契约、边界和拒绝
    条件；问题与回答分别成为绑定知识体记录、快照和哈希的不可变账本。外部认可、疑问和
    挑战入口当前只预留、不接入网络。
14. 最近工作区的每篇论文具有独立管理入口。归档会把完整工作区移入可恢复的“已归档”
    集合并记录审计；永久删除必须经过行内二次确认和 Rust 作者确认校验，删除范围包含该
    工作区的版本、分析、存证、投稿、知识体和问答，但不触碰外部原稿或已导出的投稿包。
15. 当前主稿可直接触发内容优先的初步期刊推荐；学校/机构、学院或专业、论文用途和完成投稿
    截止日期属于可选调整，作者姓名为可选本地字段且明确不参与排序。字段变化会形成新的档案或运行 ID。
    学校正式规则只有在官方来源、适用范围、有效期和核验状态完整时才应用；当前未核验时
    明确显示“候选初筛”。截止日期只用于投稿准备提示，不预测录用、见刊或数据库收录日期。
16. 作者可选择粘贴学校正式投稿/成果认定原文。Rust 在网络出口脱敏后，只向作者配置的模型发送学校名称、学科、
    论文用途和脱敏原文，要求返回受限 JSON；作者姓名、来源网址、联系方式、身份标识和论文正文不会进入请求。抽取结果保存原文
    SHA-256、来源类型、模型和规则版本，不保存原文本身。内部提示词不展示，但规则核验和
    是否采用对作者可见。中科院期刊分区表不随客户端内置；若规则包含分区条件，必须等待
    订购单位授权的官方查询接口，当前状态明确显示且不让模型猜测分区。
17. 每次期刊推荐都作为不可覆盖的本地记录绑定论文版本；再次进入“期刊匹配”可读取历史结果及
    推荐出版社。首页显示应用管理的默认资料库位置，论文管理菜单可把完整工作区原子另存到作者
    选择的文件夹，且不移动默认资料库或原始稿件。
18. 推荐候选可以由作者明确保存为当前投稿目标；目标记录绑定推荐运行和稿件版本。每篇论文
    具有独立投稿资料目录，可保存源工程、原图、可编辑表格、参考文献、补充材料、投稿信、
    标题页和声明。目标投稿包把出版社文件放入 `submission/`，把检查与选择记录隔离在
    `records/`；作者登记真实投稿时自动建立本地存证，不再将存证作为导出前置门槛。
19. 投稿路线支持唯一主线和最多 8 条有序备选支线。主线与支线分别保存期刊官方要求快照；
    每次联网访问必须重新勾选授权，默认 HTTPS；HTTP 和其他官方域名逐次确认。Rust 拒绝
    本机、私网、非公网 DNS 结果、未授权跳转和超限页面，连接绑定已验证地址。
    无法自动读取时可由作者粘贴并确认官方原文。只有带来源的明确条目才进入期刊专属清单；
    主页只承担作者指南发现，链接文字和拼音路径也可识别；动态新闻型官网仅抽取同站指南正文。
    单独出现的栏目词、文章列表和引用工具不会成为要求。备选提升需要记录上一主线状态，并保留
    目标与切换历史。
20. 目标期刊清单按文章类型与官方要求动态生成，区分目标依据、主稿与篇幅、支持文件、声明与
    作者确认；可拆分保存摘要、正文和各章节限制，并识别匿名稿、报告清单、授权或版权协议等文件。
    作者确认绑定当前目标及要求快照，目标变化后不会沿用。只有必需项和当前目标检查均完成，
    Rust 才允许导出投稿包。语法润色与语义改写不在当前范围；AI 语义语法审计标记为后续迭代。
21. 投稿附件与稿件版本、主目标、要求快照和清单上传项逐一绑定；导出前显示逐文件用途、路径、
    纳入状态、校验提示和 SHA-256。旧目标附件自动排除，必需文件不可被排除后绕过后端导出。
    双盲仅在官方证据明确要求时启用，启用后实名源稿不会进入出版社目录。当前仍未实现 PDF、Word
    和 LaTeX 的实页渲染预览，也未把结构比较冒充为页面级修订对比。
22. 选定主线后可以核对目标期刊画像。Rust 先查询本机 SQLite 目录；只有所需比较字段仍有
    缺项且作者点击该次发现动作时，才调用作者配置的模型 API。外发投影仅含期刊名、已知出版
    社、公开主页和本地已有 ISSN/EISSN，不含论文、作者、学校、工作区、评分或附件。返回结果
    作为待官网核验的不可变线索保存在当前论文工作区，不写回全局目录，也不参与推荐评分。
23. 模型与 API Key 设置恢复为顶部全局入口，导入论文前即可访问。主模型与两个备选模型仍由
    期刊发现、学校规则抽取和知识体问答共用；Key 只写入 macOS Keychain 或 Windows Credential
    Manager，前端仅获取 `hasApiKey` 状态；同一次应用运行中每个凭据只读取一次。未保存修改在关闭前
    需要确认，窄窗口改为单列设置。
24. 已选期刊的推荐卡片不再是无法操作的状态按钮；作者可在原位置发起“取消主选期刊”，经二次
    确认后解除当前主选关系。推荐档案、要求快照、附件、备选顺序和不可变选择历史继续保存在本机。
25. 投稿资料页新增始终可辨认的“图表文件”入口，把原始图件与可编辑表格分开选择；正文检测到图表时，
    即使期刊要求没有单列附件，上传槽位仍会保留。系统文件选择器和 Rust 后端共同按十类资料限制格式，
    动态清单显示允许格式；合法 UTF-16 文本可带提示接收，XLS/XLSX 伪装成 CSV/TSV 时给出真实类型和
    恢复方法。补充材料继续支持文档、数据、演示、压缩包、音视频及常见科研数据文件。
26. 目标检查不再伪装成投稿材料或显示为“缺失”。Rust 的材料完成状态只统计目标、主稿、必需附件和
    作者确认；材料齐备后，界面以独立下一步引导作者进入“检查与修订”。目标检查报告仍必须绑定当前
    稿件版本、主选期刊、官方要求和最新材料状态；附件增删、纳入状态或作者确认变化后必须重新检查，
    完成后才允许组包导出。
27. 投稿资料页新增稳定的“常见投稿附件”分类区：标题/作者信息页、投稿信、声明文件、参考文献文件、
    补充材料与研究数据，以及说明、回复与其他支持文件均可按需上传。常见入口默认是可选项，不增加
    必需项计数；若当前期刊官方清单已经定义同一文件类型，则只显示带官方证据的动态要求，避免重复。
    原生文件选择器同步区分声明、说明等类别，并提供中英双语过滤器名称。
28. AI 模型任务取消无信息增量的重复勾选：学校规则抽取和本地不足时的期刊画像发现，都在按钮旁
    明示外发字段与排除项，作者点击具体动作即完成该次授权。Rust 在一次应用运行中对每个已保存 Key
    最多读取系统凭据库一次，保存或删除后同步刷新进程缓存，避免反复触发系统确认。关键词确定性识别
    同步覆盖 `Key words`、`Key-words`、`Index Terms`、`关键字`、空格标签、不同分隔符及 IEEE/常见
    LaTeX 写法，并通过边界判断避免把正文中的相似词误报为关键词段。
29. 国内与全球推荐分别提供三层环状靶图：冲刺 2 家在靶心、匹配 3 家在中间环、保底 3 家在外环，
    坐标与右侧期刊及出版社资料一一联动；环层不冒充录用概率或公开内部算法。投稿资料页同时提供
    准备树，汇总拟组包文件、必需项、声明、可选附件和阻断，并将当前结构报告中的图表数量与对应
    上传槽位的绑定文件数比较。数量相同不替代图片精度、表格可编辑性或官方格式核验。
30. 投稿资料页以顶部按钮在准备概览、要求清单、上传资料和已存文件之间切换，一次只渲染当前区域，
    同时保留各区域计数和完整键盘操作。Rust 按当前稿件版本、目标期刊、资料类型和上传项检查同名附件；
    同名时通过中英文原生确认框取得替换授权，取消则不写入，一次选择多个同名文件则拒绝歧义操作。
    实际替换先完成新文件校验与安全复制，再移除旧工作区副本、失效旧检查并写入替换审计事件。

这些能力已经形成最小知识体领域模型和只读快照，但尚不等于可发布的完整知识体：不可变
源快照提供事实来源，结构报告提供第一层机器可读语义，规则结论和审计记录提供可追溯
判断。当前已经持久化投稿生命周期结束时的知识体记录；下一阶段需要登记稳定结构节点，
并加入 Claim、Scope、Method、Result 和 EvidenceRelation 候选的作者审核流程。

## 信任边界

- WebView 只负责呈现与发起窄命令；文件、解析、签名、存储和审计属于 Rust。
- 当前外部传输包括作者在知识体问答台主动确认的最小投影请求、期刊匹配页主动
  点击具体任务确认的学校要求抽取，以及本地资料不足时由具体发现动作确认的期刊画像发现。后者只发送公开期刊身份；
  学校要求抽取只发送学校名称、学科、用途和脱敏规则原文；这些请求都不发送源
  文件或路径。期刊官方要求查询是另一项逐次授权的受控读取：优先访问已选目标的 HTTPS 主页
  及同站作者指南，不发送论文或身份。PWC、学校网站、中科院分区接口和预印本仍没有自动网络传输命令。
  投稿包导出是作者明确选择目录的本地写入，投稿登记只记录作者在外部系统完成的事实。
- 内置规则包的临时签名私钥已销毁且从未进入仓库；公开发行前仍需建立生产密钥、
  撤销、轮换和更新通道。
- 测试只使用合成内容；仓库不包含真实未发表论文或审稿材料。

## 已知边界与下一批工作

- PDF 当前先分类并执行原生对象提取，不执行整篇 OCR；布局感知检测会标出扫描、混合、
  矢量文字或异常编码的具体候选页。普通文字、公式和表格分别路由到中英文 OCR、公式识别
  和表格结构识别，不能用普通文字 OCR 相互替代。首个文字 OCR 语言档案限定为中文（简繁）
  + 英文混排；PDFium、ONNX Runtime 和模型仍属于后续按需安装的本地增强包，依赖未就绪
  前不显示“已识别”。
- DOCX 尚未执行可逆排版转换，TEX 尚未处理多文件项目与外部资源。
- 当前国家与学科规则为 C、出版商规则为 B。期刊页面可以形成带来源的要求快照，但尚未自动
  转换成可签名、可执行的具体期刊 A 级规则包；义务强度不明确的条目始终要求作者确认。
- HTML 预览仍保存在工作区内部；投稿阶段会把它连同稿件、JSON 报告、存证和清单导出
  到作者选择的独立交付包目录。
- 版本比较目前是标题、结构、词元、图表和投稿声明的确定性差异；尚未提供逐词红线、
  外部编辑器工作副本监听、命名分支或版本库导出。
- 归档已可在本机恢复；永久删除不经过系统回收站且无法在应用内撤销。跨设备归档、加密
  备份、保留策略与机构侧删除证明尚未实现。
