# 实施工作包、依赖与完成标准

- 日期：2026-09-14。
- 当前状态：以下 W01—W14 记录 V0.54 基础核心路径；后续目录整理、材料确认快照、导航和可选 AI 的累计实现与验证见 [V0.60 实现状态](../releases/V0.60/implementation-status.md)，AI 范围见[专项说明](../optional-ai-assistance.md)。基础工作包的剩余证据仍保留在对应条目及 [V0.54 记录](../releases/V0.54/implementation-status.md) 中。
- 本文件唯一维护实施进度；[范围方案](../local-journal-package-plan.md)的 P0—P5 仅作阶段映射。

## 1. 推进顺序

```text
W01 合同与删改盘点 → W02 新项目与最小兼容 → W03 本地文件选择
W01 → W04 内置目录／规则
W03 + W04 → W05 准备视图
W03 + W04 → W06 推荐基线
W03 + W05 → W07 两任务新界面
W01 → W08 输出／渲染技术试验
W05 + W08 → W09 模板生成 → W10 DOCX安全变换／匿名
W09 + W10 → W11 预览与导出
W06 → W12 语义增强评测（可不启用）
W07 + W11 → W13 旧功能与依赖最终清理
W06 + W11 + W13 → W14 期刊覆盖与原生发布验收
```

同一实现者按依赖推进即可，不要求多代理或并行施工。已知目标路径优先打通，推荐作为独立服务接入。没有指定工期，不以任意日历日期承诺生成器难点；W08 先解决决定后续范围的技术风险。

## 2. 工作包细目

### W01 — 合同和当前调用图

- 产物：核心 Rust 类型、安全 DTO、参数化错误、命令清单；旧功能引用与删除清单。
- 任务：确定 schema 根与版本；直接目标选择删除必填推荐引用；梳理已有构建、资源、测试和平台依赖。
- 完成：catalog-origin 目标可以序列化，无推荐记录；未知值、locale、contextHash 有正反样例；核心项目不引用知识体 DTO。
- 文档：更新合同及架构中的实际名称，记录与草案的差异，不新增空包或假脚本。
- 状态：部分实现；核心合同和持久化 requestId 已接入全部生成／修改操作，同请求并发与重启复用有测试；命令先持久化 queued job 并立即返回 jobId，后台写入 running／终态及类型化结果，同时推送顺序事件，前端以事件为主、查询为恢复兜底并可请求取消。启动中断恢复已实现；解析器／编译器内部的细粒度协作式取消检查点仍待补齐。证据见 [V0.54 实现状态](../releases/V0.54/implementation-status.md)。

### W02 — 新项目存储与最小历史读取

- 依赖：W01。
- 产物：ProjectStore、SourceSnapshot、revision 更新、最近任务隐藏与恢复索引。
- 任务：临时写入与原子提交、索引重建、单项目锁、重复 requestId、请求及生成包中断恢复。
- 完成：合成项目创建、重开、坏记录隔离、隐藏与恢复最近任务；源稿和项目文件字节不变。
- 可删：旧 WorkspaceLifecycle、知识体持久化 API 的新路径依赖；早期任务扫描、导入和迁移不保留。
- 状态：已实现；新存储使用临时目录提交、索引扫描、进程内 mutex 与跨进程文件锁、revision、requestId 幂等和请求／生成包重启恢复。材料从一次读取的字节建立项目快照，检查不再依赖之后可能变化的外部路径；失败原子写和未提交材料目录会清理。V0.54 已删除未上线的早期任务扫描、导入、迁移记录与兼容测试，不读取旧根，也不主动删除磁盘上的旧文件。PDF／DOCX 均可创建新项目；同一规范化文件夹由 Rust 专有绑定复用同一项目 ID，主稿变化新增不可变 source version；正式投稿包对可编辑 DOCX 的要求另行显式校验。

## 4. 主要风险的前置处理

| 风险 | 前置工作 | 不通过的处理 |
| --- | --- | --- |
| 旧推荐耦合阻碍直接选目标 | W01，首先设计可空推荐引用 | 重写类型和命令，不给已知目标伪造推荐记录 |

| 早期任务兼容复杂度蔓延 | W02 不保留兼容运行时 | 不扫描、不导入、不迁移，也不主动删除磁盘文件 |
