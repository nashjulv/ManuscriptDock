## 1. 实现原则

围绕“推荐期刊”和“按目标期刊整理投稿包”重建实现。用户已明确允许重写或删除旧代码、接口、交互和无用功能；不以保留旧页面、模型或状态机作为设计目标。只保留能证明有价值的基础能力与数据完整性约束。

删除旧产品代码、隐藏最近任务与删除用户文件是不同操作：V0.54 已移除无用运行时代码和未上线的早期任务扫描／导入／迁移功能；最近任务“移除”仅写入可恢复隐藏索引。应用不主动清理旧目录，但也不再读取它们或创建新版副本。

## 3. 首批交付定义

- 同一个桌面应用内的两个任务；已知目标不依赖任何推荐记录。
- 打开本地 PDF、DOCX 或材料文件夹，直接处理，自动保存并恢复进度；同一个规范化文件夹始终对应同一个项目记录。
- 一页偏好与最多三个解释充分的候选，硬条件未知不冒充通过。
- 按内置目标规则整理必要文件，作者补事实，预览后本地保存。
- 公开期刊规则由团队 AI 辅助整理并人工核验后维护仓库配置，不建设维护功能；作者可另行启用[有限的 AI 材料辅助](../optional-ai-assistance.md)，每次预览并确认。
- 正式版本不依赖云端模型、期刊实时抓取、PWC、账号或首次在线下载。
- 实际生成能力以经过测试的文档特征与规则覆盖为界，不能用源稿复制代替自动整理完成。

## 4. 决策等级

已确定：Tauri/Rust/React、两个任务、新 IPC、只读原稿、模板文档与受限 OOXML 变换、配置内置、移除旧生命周期能力；V0.60 的可选模型调用使用独立受控路径，不恢复旧远程工作流。

仍需在对应工作包内完成的技术试验：DOCX 实页预览与报告 PDF 的可发行本地渲染器。XLSX 已采用 Rust 写库并验证字符串／Unicode／单页横向输出；本地嵌入模型因缺少授权发行与独立效果证据而明确不启用，保留确定性推荐。详见整理器、推荐和工作包文档。

需由真实样本决定：首个子领域与文章类型、最终 10—20 本期刊、性能支持档案。准备规则和编译器可先用合成稿件及 3 本真实规则试点；扩大覆盖前确定这些选择。

V0.54 建立本地双任务运行时。V0.55—V0.60 增加目录图标／列表与拖拽、目标期刊同心圆、中文选刊修复、材料模板与草稿、检查和作者确认快照、固定首页入口，以及可选 AI 起草与检查。最新自动化、浏览器验收及未完成边界见 [V0.60 实现状态](../releases/V0.60/implementation-status.md)。代码通过工作分支交付；Git 提交和远端分支是交付凭据，不等于已发布安装包或完成真实模型验收。

W01—W14 基础工作包的状态见 [实施计划](delivery-plan.md)；本轮增量能力和验证记录见 V0.60 实现状态。早期链接检查数量属于当时快照，不代表当前文档总数。

Internationalization review：当前界面和参数化错误支持 `zh-CN`／`en`，新增摘要、关键词、CRediT、生成式 AI 披露、附件用途、快照异常和规则证据均有双语文案与组件／映射测试；稿件科学内容不翻译。生成给出版社的文档目前为英文，作者工具中的固定双语说明仍需随正式模板视觉验收继续检查。
