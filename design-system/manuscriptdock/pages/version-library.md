# 版本库页面覆盖规则

本页继承 `../MASTER.md`，只补充版本管理特有规则。

## 信息层级

1. 当前唯一主操作：选择修改稿或保存新版本；
2. 不可变版本时间线；
3. 选择旧版后出现的恢复操作；
4. 右侧只读确定性差异。

## 交互语言

- 使用“保存版本、版本说明、当前、比较、恢复为新版本”；
- 不向普通作者展示 commit、HEAD、checkout、detached、rebase；
- 恢复按钮必须完整写明“恢复 vN 为新版本”，不能简称“回退”；
- 重复内容明确反馈“未创建重复版本”，不能表现为失败；
- 格式不一致时在文件卡片内说明原因与正确去向。

## 视觉与可访问性

- 时间线依靠线、节点、版本号和文字共同表达状态，不只依赖颜色；
- 当前节点使用 `#A6CE39`，其余保持中性灰阶；
- 版本行至少 48px，支持键盘选择并公开 `aria-pressed`；
- 版本说明使用可见标签、200 字计数和本地示例；
- 窄屏下选择文件与保存按钮扩展到至少 44px 高，标题比较改为纵向；
- 差异中的新增与移除同时显示 `+` / `−` 符号和分组标题。
